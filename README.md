Candy Crush Game
Description:

This project is a simplified version of the Candy Crush game developed using HTML, CSS, and JavaScript. The game generates a 9x9 board filled with random candies. Players can drag and swap candies to create combinations of three matching candies. Matching candies are removed from the board automatically.

Features:
9x9 game board,
Random candy generation,
Drag-and-drop functionality,
Match-three detection,
Automatic candy removal,
Score tracking

Technologies Used:
HTML,
CSS,
JavaScript

How to Run the Project:
Download or clone the repository.
Open the project folder in Visual Studio Code.
Make sure all image files are located inside the images folder.
Open the index.html file in a web browser.
Start playing the game by dragging candies to create matching combinations.
